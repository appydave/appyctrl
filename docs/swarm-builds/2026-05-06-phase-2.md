## Architectural decisions

1. **Lock the cross-slice contracts in the planner brief, not in code.** Three coders running in parallel can drift on hook signatures, prop shapes, and module paths. The planner brief explicitly stated `useAppRegistry` return type, `AppyAppRowProps`, `AppyAppModalProps`, and the registry import path (`@t3tools/appydave-registry/registry`). All three coders converged on the same imports independently — zero rework needed at integration.

2. **Researcher one-shot, not a researcher subagent + planner subagent.** The Sidebar slot is a discrete read-once question. Spawning a planner subagent to consume the researcher report adds a coordination hop without value when I (the integrator) can synthesise the briefs directly. Planner is overhead for tasks ≤ a few hours of work.

3. **Splash discipline: don't modify upstream's `SplashScreen.tsx` — replace at the seam.** The previous `splash-pending` patch already pointed at upstream's component via `pendingComponent: SplashScreen`. Repointing at a new `AppySplashScreen` is a one-character edit that keeps `SplashScreen.tsx` 100% upstream-clean. Upstream rebases never touch our brand surface.

4. **Workspace package for shared types.** `packages/appydave/` (named `@t3tools/appydave-registry` to match the workspace's `@t3tools/*` convention) holds the `RegisteredApp` type + storage helpers. Coder-1 created it; coders 2 + 3 imported from it. Sets up Phase 3 to share the same types when the webview route is built.

## Gotchas / watch out for

- **Subagents can't share each other's typecheck output.** Coder-1 and coder-2 both reported "typecheck fails on coder-3's missing module" or similar — they cleared their own files but couldn't verify integration. Plan accordingly: integrator must run final `bun typecheck` after all slices land.
- **Subagents created phantom `.claude-flow/data/pending-insights.jsonl` files.** Ruflo's hooks fire on Bash commands run anywhere in the tree, leaking `.claude-flow/` directories under `apps/web/`. Tracked accidentally in this commit. Add `**/.claude-flow/` to `.gitignore` (existing rule only covers `.appydave/design-poc/**/.claude-flow/`).
- **Workspace package detection requires `bun install`.** When coder-1 added the new dep to `apps/web/package.json`, `bun install` had to run to regenerate `bun.lock`. Coder-1 ran it, but UAT requires re-running on the user's machine after `git pull`.
- **`exactOptionalPropertyTypes: true` is strict.** Both coder-1 and coder-3 hit it independently — `glyph: undefined` is not assignable to `glyph?: string`. Pattern: `glyph ? { ...rest, glyph } : rest`. Worth noting in the spec template for future phases that touch optional fields.
- **Researcher-as-subagent paid off.** The 700-word slot report saved each of three coders ~10 min of independent Sidebar.tsx exploration + reduced their probability of slotting `<AppyAppsSection />` in the wrong place. Same researcher → 3 coders pattern is reusable for any phase that touches a non-trivial upstream component.
- **The `splash-pending` and `splash-appy-logo` patches now travel together.** Both modify the same import + the same `pendingComponent` line in `__root.tsx`. The annotation on that line cites both patch ids. Future rebase work should treat them as a unit.
- **Click on an app row body does nothing yet.** Phase 3 deliberate. Don't ship to anyone outside without a marker (toast, "coming soon" tooltip) if the dead-click would confuse them.
